# Quy tắc bàn giao bắt buộc: Luôn gửi danh sách các file đã thay đổi

Trong **mọi phản hồi sau khi hoàn thành công việc hoặc sửa code**, trợ lý AI **BẮT BUỘC** phải:

1. Liệt kê danh sách đầy đủ tất cả các file đã được tạo mới hoặc chỉnh sửa trong phiên làm việc.
2. Định dạng mỗi file dưới dạng clickable markdown link: `[filename](file:///đường_dẫn_tuyệt_đối_hoặc_tương_đối)`.
3. Đi kèm tóm tắt ngắn gọn các thay đổi cụ thể và nơi người dùng / quản trị viên có thể cấu hình dữ liệu liên quan.
